References & Learning Resources

The following reputable sources support further research and will be used to expand this project in future milestones.

  • National Institute of Standards and Technology (NIST) — Cybersecurity Framework: security risk management guidance.
  • OWASP — Top 10 Web Application Security Risks: major categories of web application risks.
  • OWASP Cheat Sheet Series: practical secure development recommendations.
  • MDN Web Docs — Web Security: browser and web platform security concepts.
  • CISA — Secure Our World: everyday cybersecurity habits.
  • KSU IT 3203 course website: course materials and project context.
